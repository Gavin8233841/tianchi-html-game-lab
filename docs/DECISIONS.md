## 2026-11-19：v2 推理深化（用户试玩 v1 反馈驱动）

- 用户试玩 v1 后反馈：节奏太快；事件要像雷一样藏着自己挖出来；数字要包含事件；要更多可玩性。据此升级 v2。
- 数字 = 邻格「雷 + 事件」总数（原料/出口不计入），事件进入推理层（回到最初录音设想，取代 v1 只数雷）。
- 新增「探测」（耗 1 体力安全认清：雷→明雷不扣血、事件→认出种类但未触发、安全格单格翻开不连锁）与「标记旗」（免费纯标记）；挖已认出的事件才触发好坏。三模式 [挖][探][旗] + 右键恒为旗。
- 节奏放慢组合拳：首击只保无雷（事件可邻→首击常出数字需思考）、0 连锁因数字含事件自然变小、棋盘加大 L1 9×9 / L2 12×10、特殊格更多、体力上调。bot 校准 L1 平均操作 ≈10.6 次（v1 仅 3.7）。
- 张力校准：贪 L2 全齐 48% / 死亡 23.5%（目标区间内）；shield 初始回到 2（探测提供安全容错）。

## 2026-11-19：v3 手感与积累（用户试玩 v2 反馈驱动）

- 用户试玩 v2 后反馈三条：①体力太多、探索成本低；②事件弹太快看不清作用；③探索多余的原料要保存。据此升级 v3。
- 体力收紧：L1 34→26、L2 42→38。bot 1000 局校准：贪 L2 全齐 46.1% / 死亡 22.0% / 紧急 24.5%（体力成为真实威胁）。再收紧 L1 会推高紧急撤离→少存水→拖累 L2 全齐，26 为保张力下限。
- 事件大卡片：触发时弹出图标+名称+说明+数值变化的大卡片，停留 2.4s（底部倒计时条），期间锁输入，多事件依次排队；取代原先 1.5s 小 toast，让玩家看清作用。逻辑仍当帧完成（存档/刷新安全）。
- 余料入酒馆持久仓库：结算余料不再折成「只显示」的钱，改为存入跨局仓库（独立 localStorage 键 star-tavern-warehouse-v1），酒馆与结算页可见库存。settlement.banked 标记防刷新重复入库。本期只存不用，用途留给后续酒馆扩展（用户明确）。

## 2026-11-19：v4 原料探索化（用户试玩 v3 反馈驱动）

- 用户反馈：水/星尘要像雷和随机事件一样靠探索逐步获得，「点一下就有好多」体验差。据此 v4。
- 原料改小量多格：L1 water 30×4 → 10×9（单格 +10ml=1/6 管，不再一下半管）；L2 water 15×4 → 10×6、stardust [2,2,3,5] → [1,1,1,1,2,2,2,2]（单格 +1/2g）。凑满配方需多次发现，原料成为探索目标。
- 配方不变（水60+星6）；体力沿用 v3（26/38）。原料变难收集后同样体力自然更紧，无需再调。
- bot 1000 局：贪L2 全齐 51.2% / 死亡 21.2% / 紧急 23.3%；L2 操作 20.2 次/层（探索量上升）。

## 2026-11-19：v5 原料逐格收集（用户「L1 点一下水就满」反馈驱动）

- 根源：洪水连锁+自动拾取 → 大连锁一次扫满水。v4 小量多格仍会被大连锁扫满。
- v5 语义：连锁只「揭示」原料不自动赠送；仅被点击格自动收集，其余原料揭示后留在原地，点一下免费收集（+10ml/格）。单次点击最多 +10ml，杜绝一下满管。
- 离层（出口/紧急）时自动收走「已揭示未拾取」原料——看见的都能带走，不浪费（修复收集制在出口结束时的丢弃缺陷）。
- 原料仍不计入 adj；雷/事件语义不变。玩法提示更新「连锁翻出的原料点一下才收集」。
- bot 1000 局：贪L2 全齐 50.0% / 死亡 23.1% / 紧急 22.2%；L1 操作 12.9 / L2 22.9 次/层。新增单测㉜，共 35 全绿。
